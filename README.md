A program that writes one funny real-life patch note to `/output/entry.txt`,
for the make.fun competition
[Real-Life Patch Notes: The Comedy Changelog](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). Pass `-h` or `--help` to print a
short usage line instead of writing. No network, no clock, no
randomness. The entry is 133 characters, inside the 1 to 160 gate.

## The entry

```
v5.1.0: Fixed bug where the body woke up one minute before the alarm every morning; sleep now ends on schedule, not one minute early.
```
